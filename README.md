PUBLISH ON NETLIFY
1. Extract this ZIP on your computer.
2. Open the extracted folder and make sure index.html is directly inside it, alongside styles.css, script.js and the assets folder.
3. Open https://app.netlify.com/drop and drag the extracted folder (or the files/folder together) into the drop area. Netlify generally needs the extracted site folder, not the ZIP file itself.
